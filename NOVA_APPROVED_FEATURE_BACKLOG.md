# Nova Approved Feature Backlog

Purpose:
This file lists feature areas the local guarded loop may consider. It may not invent large new feature categories without Daniel's approval.

Approved feature themes:
1. Better project-state memory and "continue where left off" reliability.
2. Better release/current-version awareness.
3. Better command/help consistency and command verification.
4. Better model timeout/fallback behaviour.
5. Better generated report hygiene.
6. Better local autonomous loop safety and evidence tracking.
7. Better user-facing sanity checks for chat/help/write/read/verify/code/do.
8. Better logs/test-result memory to prevent repeated mistakes.

Feature rules:
- New functionality must be small and test-backed.
- Prefer source + test changes together.
- Do not redesign GUI.
- Do not add flashy new categories.
- Do not package a release automatically.
- If a feature requires external research, write a research note first and stop.
- If unsure, ask Daniel.
